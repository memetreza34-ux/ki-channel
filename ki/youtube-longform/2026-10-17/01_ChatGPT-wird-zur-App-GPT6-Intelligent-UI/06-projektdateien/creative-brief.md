# Creative Brief – ChatGPT wird zur App: Was GPT-6 jetzt verändert

**Themencheck:** GPT-6 Intelligent UI am 07.10.2026 von OpenAI veröffentlicht; aktueller Anlass, konkreter neuer Nutzen. Keine anderen bestehenden Repo-Themen doppelt.

**Viewer Promise:** Nach circa 5½ Minuten weiß man, was Intelligent UI neu macht, wie es laut Anbieter funktioniert, wofür es sinnvoll ist und was es NICHT beweist.

**Hook tension:** Früher vor allem Text, heute kann die Antwort bedienbar werden. Ist das wirklich eine App?

**3-second proof (Frame 0):** Bereits sichtbar: großer Vergleich TEXT → TOOL, ein Diagramm verändert den Wert, kein leerer Intro-Hold.

**Warum Zuschauer interessiert:** weniger Umwege beim Vergleichen, Lernen und kleinen Alltagsaufgaben.

**Kernmechanismus:** Frage → Darstellungsentscheidung → native UI-Bausteine → nutzbare Antwort; als vereinfachte Grafik eindeutig gekennzeichnet.

**Dramaturgie:** schneller Aha-Hook → konkrete Differenz → Architektur → zwei praktische visuelle Beispiele → Denkfalle/Korrektheit → Rollout und Grenzen → zukunftsgerichteter Payoff.

**Memorable moments:** Text sprengt sich in Bedienelemente (00:00), Sparsumme reagiert auf Slider (Kapitel 4), Lampe leuchtet beim geschlossenen Schalter (Kapitel 5).

**Truth risk:** Marketing-/Feature-Claims, Plan/Client-Unterstützung, vermeintlich reale ChatGPT-Screenshots, unüberprüfte KI-Korrektheit. Gegenmaßnahmen: Source Ledger, illustrative Kennzeichnung, keine Benchmarks, Release-Recheck.

**Absichtlich vermieden:** generische Roboter, Neon-Cyberpunk, immer gleiche Karten, ein Sprechertext als Vollbild, Fake-Produktbeweise, künstlich verlängerte Dauer.

**Verbesserungsziel dieses Videos:** größerer sichtbarer Mechanismus pro Kapitel; mehrere verschiedene Visual-Familien; prüfbare Verbesserungsakte direkt nach dem ersten echten Render.
