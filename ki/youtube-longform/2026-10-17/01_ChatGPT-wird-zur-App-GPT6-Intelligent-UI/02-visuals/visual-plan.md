# Visuelle Dramaturgie – ChatGPT wird zur App: Was GPT-6 jetzt verändert

Siehe `image-prompts.md` (zugleich verbindlicher Bildprompt-Link). Pro Kapitel semantische Zustandsänderung; illustrative UI immer mit **SCHEMATISCHE ILLUSTRATION** markieren, wenn der Vergleich zu einer realen Oberfläche naheliegt.

**Bildrahmen:** 1920×1080, 30fps, keine dauerhaften Volltext-Untertitel. Großflächige Icons/Objekte, selten Panels; sprechende Visualverben statt Kartenserien. Nach 30–45 Sekunden neues visuelles Motiv. Jede Szene reagiert auch während längerer Sprecherpassagen auf einen neuen Gedanken. Finale Schnittgrenzen erst mit echter Sprache.

| Kapitel | Hauptverb | Start → Änderung → Ende | Hero | Kamera / Grammatik |
|---|---|---|---|---|
| Hook | verwandelt | Text → Regler/Diagramm → nutzbares Ergebnis | schwebender Regler | Typo-/Objektmorph |
| Darstellung | kontrastiert | Absatz → Vergleich → Fokus | Side-by-side-Differenz | Split-Screen |
| Mechanismus | verbindet | Prompt → Komponenten → Layout | leuchtender Pfad | breiter Pipeline-Shot |
| Sparrechner | rechnet | 20×10 → 200; 30×10 → 300 | steigendes Diagramm | Datenvisualisierung |
| Lernen | schließt | offener Kreis → Kontakt → Licht | Lampen-Illustration | physischer Schaltplan |
| Risiken | prüft | schöne Zahl → Fehlersignal → Prüfschritt | Warn-Overlay | Diagnose / X-Ray |
| Verfügbarkeit | trennt | Chat/Work/Voice → Markierung der Grenzen | 3 Modus-Lanes | editorialer Statusplan |
| Payoff | bündelt | Text / Diagramm / Tool → situationsgerechte Antwort | drei verbundenen Systeme | offene Objektkomposition |

**Motion:** deterministische Remotion-Frames; Einblendung ist nicht der einzige visuelle Vorgang. Keine Netzwerkaufrufe oder fehlende Assets im Render. Farben, Layout, Beispiele sind Illustration, nicht Beweismittel für tatsächliches UI-Verhalten.
