# Visual Plan

Alle Kapitel sind `REMOTION_NATIVE`. Keine externen Bilder geplant.

| Kapitel | Hauptvisual | Zustandsentwicklung |
|---|---|---|
| Hook | Prompt-Karte → App-System | einzelner Prompt zerlegt sich in klaren Workflow |
| Problem | Nutzer/Input/Ergebnis | vage Idee wird auf 3 Kernfragen reduziert |
| Nutzerfluss | App-State-Map | Eingabe → Aktion → Zustand → UI |
| Repository | Projektordner + Commit-Timeline | Dateien ordnen sich, Commit setzt stabilen Punkt |
| Kontext & Bauen | 4-Fragen-Arbeitsauftrag + Komponenten | Mega-Prompt wird in überprüfbare Schritte zerlegt |
| Testen | Browser-Testfläche + Fehlerzustand | Fehler reproduzieren → Ursache markieren → Fix verifizieren |
| Branches | Git-Branch-Graph | stabile Linie → Experiment → Merge oder Verwerfen |
| Abschluss | kompletter Prototyp + Workflow-Pipeline | alle Schritte werden als überprüfbare Kette zusammengeführt |

Technik: React, SVG, CSS, pseudo-3D, Schatten, Layering und Remotion-Interpolation. Keine Screenshot-UI.
