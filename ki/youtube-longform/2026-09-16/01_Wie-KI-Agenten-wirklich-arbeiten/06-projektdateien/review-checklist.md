# Review Checklist

## Inhalt
- [ ] Sprechertext entspricht exakt der freigegebenen Phase-1-Fassung
- [ ] Chatbot vs. Agent wird nicht als bloßes „stärkeres Modell“ erklärt
- [ ] Modell, Regeln, Tools und Kontext sind klar unterscheidbar
- [ ] Agenten-Loop ist ohne Sprecher verständlich
- [ ] Fehlerfortpflanzung und Fremdinstruktion werden als Risiko, nicht als Fähigkeit gefeiert
- [ ] Workflow vs. Agent wird ausgewogen eingeordnet

## Visuals
- [ ] alle 46 geplanten Beats haben eine sichtbare semantische Reaktion
- [ ] 16:9-Elemente sind auf Laptop/TV groß genug
- [ ] kein Transcript als dauerhafte Bildschirmfläche
- [ ] keine internen Goal-/Planner-/Debug-Texte sichtbar
- [ ] keine zufällige Deko-Motion
- [ ] Kapitel enden mit lesbarem Hold
- [ ] Rot nur Risiko/Fehler; Grün nur verifizierter Erfolg

## Audio / Timeline
- [ ] echtes Voiceover integriert
- [ ] Kapitelgrenzen an echte Sprechpausen angepasst
- [ ] Beat-Wechsel folgen der gesprochenen Bedeutung
- [ ] ggf. Retiming dokumentiert und natürlich klingend

## Technik
- [ ] Contract-Test ausgeführt
- [ ] TypeScript ausgeführt
- [ ] Repo-/Runtime-Checks ausgeführt
- [ ] Smoke-Frames tatsächlich angesehen
- [ ] finales MP4 technisch geprüft
- [ ] finales MP4 normal angesehen

## Thumbnail / Packaging
- [ ] Thumbnail separat gerendert
- [ ] Thumbnail klein lesbar
- [ ] Titel und Thumbnail ergänzen sich
- [ ] Titel verspricht nicht mehr als das Video liefert
- [ ] finale Kapitel-Timestamps aus echtem Audio eingetragen
