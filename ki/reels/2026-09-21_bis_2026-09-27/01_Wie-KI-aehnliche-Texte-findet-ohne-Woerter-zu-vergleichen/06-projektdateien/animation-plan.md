# Animation Plan — Visual Beats

**Grundsatz:** Alle Visuals sind `NEW_BUILD` innerhalb `REMOTION_NATIVE`. Phase 3 verschiebt Beat-Grenzen am echten Voiceover; Stimme, Visual Beat, Caption-Fokus und Zustandswechsel müssen denselben Moment treffen.

| Beat | Sprecherstelle | Start → Bewegung → Ende | Umsetzung | Phase-1-Timing |
|---|---|---|---|---|
| B1 | „beste Fundstelle … andere Wörter“ | Query oben → anders formulierter Treffer fährt ein → beide bleiben sichtbar | NEW_BUILD | S1 früh |
| B2 | „semantische Suche“ | graue Wortlinie verliert Fokus → lila Bedeutungsbogen zeichnet sich → Match-Puls | NEW_BUILD | S1 spät |
| B3 | „Embeddings verwandelt“ | Textkarte → komprimiert sich → Vektor-Kern | NEW_BUILD | S2 früh |
| B4 | „Vektor … Liste von Zahlen“ | Kern → sechs Dimensionssäulen d₁…d₆ fahren aus → stabiler Vektor | NEW_BUILD | S2 Mitte/spät |
| B5 | „zusammenhängen“ | verstreute Punkte → drei Themenfarben gruppieren sich → Cluster werden benannt | NEW_BUILD | S3 früh |
| B6 | „näher beieinander“ | Abstandsring → zieht sich zusammen → verwandte Punkte pulsieren gemeinsam | NEW_BUILD | S3 Mitte |
| B7 | „kaum dieselben Wörter“ | Query-Punkt außerhalb → Kurvenflug → landet im passenden Cluster | NEW_BUILD | S3 spät / HERO |
| B8 | „Anfrage eingebettet“ | Query-Text → faltet ein → Punkt mit Q entsteht | NEW_BUILD | S4 früh |
| B9 | „vergleicht ihren Vektor“ | Q → Linien zu drei Kandidaten → Linien reagieren nacheinander | NEW_BUILD | S4 Mitte |
| B10 | „ordnet Treffer“ | Kandidaten → zwei dimmen → nächster Kandidat bekommt lila Ring + Rang 1 | NEW_BUILD | S4 spät |
| B11 | „Suche, Clustering und Empfehlungen“ | drei große Icons aktivieren nacheinander | NEW_BUILD | S5 früh/mittel |
| B12 | „nicht automatisch Wahrheit … Bedeutung“ | Use Cases rücken hoch → Grenze erscheint → Schlussregel skaliert ein | NEW_BUILD | S5 spät |

Keine weichen Übergänge als Selbstzweck. Hard Cuts zwischen Szenen; Bewegung innerhalb der Szenen trägt den Flow.
