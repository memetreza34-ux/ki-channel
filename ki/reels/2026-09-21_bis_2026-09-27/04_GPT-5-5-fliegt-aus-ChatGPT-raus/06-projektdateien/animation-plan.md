# Animation Plan

## Global
- 1080×1920, 30fps, 36s Planungsdauer
- Captions über `REEL_CAPTION_SAFE`, aktuell `bottom: 300`, max. 820px, max. 2 Zeilen, max. 6 Wörter pro Cue
- Hauptvisuals enden vor der Caption-Zone
- Finaler Build vollständig Remotion
- keine Render-Time-Netzwerkaufrufe
- keine Fake-Produkt-Screenshots

## S1 — Deadline Gate · 0–180
1. ChatGPT BrandAnchor + `UPDATE` Signal.
2. GPT-5.5 Hero-Token springt in einen perspektivischen Track.
3. Kalender `14 OKT` baut sich als Gate auf.
4. Gate schließt; Modell stoppt davor; CTA `VORHER PRÜFEN` erscheint.

## S2 — Betroffene Produkte · 180–360
1. GPT-5.5-Kern erscheint zentral.
2. Drei Knoten `ChatGPT`, `WORK`, `CODEX` docken an.
3. Pfade werden nacheinander gesperrt.
4. Badge `ALLE PLÄNE` spannt sich über das Netz.

## S3 — API-Ausnahme · 360–540
1. Bildschirm teilt sich in obere und untere Route.
2. Obere Produkt-Route läuft gegen `14 OKT`-Barriere.
3. API-Lane zeichnet sich grün weiter.
4. `NICHT BETROFFEN` wird als Zielstatus sichtbar.

## S4 — Codex-Migration · 540–720
1. Terminal-Rahmen klappt räumlich auf.
2. `gpt-5.5` wird als alter Slot markiert und ausgeworfen.
3. Connector zieht `gpt-5.6-sol` in den Slot.
4. Sol-Zustand bestätigt sich mit Terminal-Prompt + Check.

## S5 — Audit · 720–900
1. Audit-Tree mit Defaults, Saved Model, Agents, Tasks, Scripts entsteht.
2. Scanner fährt vertikal/horizontal durch die Einträge.
3. GPT-5.5-Referenzen blinken als Treffer.
4. Treffer wechseln in `PRÜFEN`/Check-Zustand.

## S6 — Schlussurteil · 900–1080
1. `14 OKT` steht als zentraler Zeitanker.
2. ChatGPT / Work / Codex laufen in drei geschlossene Pfade.
3. API bleibt auf offener grüner Spur.
4. Codex-Migrationspfeil dockt an `GPT-5.6 SOL`; Schlussstatus hält mindestens 24 Frames.
