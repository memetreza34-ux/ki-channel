# Review-Checkliste

- [x] kanonische Ordnerstruktur
- [x] acht eindeutige Icons und Hauptmechaniken im Paket
- [x] zentrale Caption-Geometrie im Source
- [x] maximal sechs sichtbare Caption-Wörter
- [x] keine Fortschrittslinie und keine Caption-Karte
- [ ] neues Audio mit höchstens 60 Sekunden
- [ ] Synchronisation gegen neues Audio
- [ ] Typecheck und Tests
- [x] Migrations-Smoke-Frames: Zwischen- und Ergebniszustand jeder Szene
- [x] statische Visual-QA der aktuellen Migrationsframes
- [ ] Smoke-Frames nach neuem Audio
- [ ] visuelle Smartphone-QA
- [ ] finaler MP4-Export
