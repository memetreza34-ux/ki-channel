# 02 — Bilder / Videos / Brand Assets

Level-Up v3: reale/official Medien sind gezielte Story-Beweise, keine Füllbilder.

Geplante Priorität:

1. **Anthropic / Claude Brand** — offizielles Wordmark/Press-Kit oder echte Produkt-UI, lokal + Provenance.
2. **Fable 5.1** — echter offizieller Product-/Pricing-Crop von `anthropic.com/claude/fable`.
3. **Mythos 5.1** — echter offizieller Product-/Access-Crop von `anthropic.com/claude/mythos`.
4. **Launch-Proof** — offizieller Newsroom-Crop „Introducing Claude Fable 5.1 and Claude Mythos 5.1“.

Keine generischen Brain-/Spark-Icons als Claude-Logo. Wenn ein offizielles Logo nicht sauber lokal auflösbar ist, klare Typografie `ANTHROPIC` / `CLAUDE` statt Fake-Rekonstruktion.

Keine Render-Time-Remote-Medien. Finale Assets erst nach Rechte-/Provenance-/SHA256-Prüfung in Produktion übernehmen.
