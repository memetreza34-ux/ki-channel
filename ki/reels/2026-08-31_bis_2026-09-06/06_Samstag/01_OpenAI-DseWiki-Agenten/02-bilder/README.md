# 02 — Bilder / Videos / Brand Assets

Phase 1 bleibt native-first. Geplante reale/offizielle Momente dürfen erst nach lokalem Rechte-/Provenance-Review materialisiert werden.

Priorität:
1. geprüftes offizielles OpenAI-Wordmark/Brand-Asset oder typografischer Name als Fallback;
2. sauberer Quellen-/Research-Crop, falls lokal und rechtlich geprüft;
3. DseWiki-/Research-Screenshot nur als lokales geprüftes Asset;
4. sonst native Remotion-Erklärung.

Keine Fake-Logos, keine Google-Bildsuche als Lizenznachweis, keine Remote-Medien im Render.
