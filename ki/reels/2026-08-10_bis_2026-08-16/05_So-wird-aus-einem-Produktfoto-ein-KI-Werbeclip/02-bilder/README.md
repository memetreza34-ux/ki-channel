# 02 — Bilder

Für die **laufenden Szenen** bleiben externe Bilder optional; die Erklärvisuals werden weiterhin als reel-spezifische Remotion-Mechaniken gebaut.

Für das **Cover** ist jetzt ausdrücklich ein eigenständiges, hochwertiges Hero-Bild vorgesehen. Das bisherige Cover aus einem normalen Reel-Frame ist nicht freigabefähig.

Verbindlich:
- Cover nicht als Screenshot einer normalen Szene verwenden.
- kein Untertitelblock auf dem Cover.
- keine winzigen UI-Karten als Hauptmotiv.
- keine große leere Mitte.
- ein einziges sofort verständliches Vorher/Nachher-Motiv: schlichtes Produktfoto → hochwertiger KI-Werbeclip-Look.
- Produkt muss links und rechts eindeutig dasselbe bleiben.
- visuelle Transformation muss in Smartphone-Größe in unter einer Sekunde verständlich sein.
- Brand-Farben Weiß / `#6E45C9` / `#B98CFF` nutzen, aber Bildwirkung vor Dekoration priorisieren.
- final als `cover.png` oder `cover.jpg` in diesem Ordner ablegen.

Siehe `cover-brief.md` für das genaue Generierungsbriefing.
