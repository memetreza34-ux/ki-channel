# Animation Plan — Visual Beats

**Grundsatz:** Inhalt zuerst. Jeder Beat ist `NEW_BUILD`; keine bestehende Library-Animation bildet die konkrete Werbeclip-Mechanik exakt genug ab.

| Beat | Sprecherstelle | Gemeinte Aussage | Start → Bewegung → Ende | Umsetzung |
|---|---|---|---|---|
| P1 | „Produktfoto“ | ein simples Ausgangsasset | einzelnes Produkt → zentriert groß sichtbar | NEW_BUILD |
| P2 | „Mach daraus Werbung“ | vager Prompt | Prompt-Chip → wird an Produkt gekoppelt | NEW_BUILD |
| P3 | „beliebige Ergebnisse“ | fehlende Richtung erzeugt Drift | 1 Produkt → 3 stilistisch widersprüchliche Varianten | NEW_BUILD |
| P4 | „was verkauft wird“ | Produktkern festlegen | Produktkarte → Kernnutzen wird fixiert | NEW_BUILD |
| P5 | „für wen“ | Zielgruppe bestimmt Gestaltung | offener Audience-Slot → Zielgruppe rastet ein | NEW_BUILD |
| P6 | „welche Stimmung“ | Mood steuert Bildsprache | neutrale Fläche → klarer Mood-Look | NEW_BUILD |
| P7 | „visueller Plan“ | Brief wird Ablauf | 3 Entscheidungen → 5 Storyboard-Schritte | NEW_BUILD |
| P8 | „nicht sofort alles animiert“ | erst statische Basis | Motion-Symbol stoppt → Keyframe-Modus aktiv | NEW_BUILD |
| P9 | „konsistente Schlüsselbilder“ | gleiche Produktidentität | 1 Produktanker → 4 Keyframes erscheinen | NEW_BUILD |
| P10 | „nicht springen“ | Drift vermeiden | Warn-Variante → Form/Farbe korrigiert → Konsistenz-Linie grün | NEW_BUILD |
| P11 | „in kurze Bewegungen“ | Keyframes werden Clips | statische Frames → Bewegungsindikatoren laufen | NEW_BUILD |
| P12 | „Ablauf zusammengesetzt“ | Clips werden Sequenz | Einzelclips → Timeline → zusammenhängender Rohclip | NEW_BUILD |
| P13 | „Logo, Text, Produktdetails, Übergänge“ | vier Prüfbereiche | Rohclip → Scanner prüft vier Zonen | NEW_BUILD |
| P14 | „kleine Fehler“ | Fehler wirken sofort sichtbar | rote Marker → Problembereiche fokussieren | NEW_BUILD |
| P15 | „Workflow“ | systematischer Prozess | fünf Prozessschritte leuchten nacheinander | NEW_BUILD |
| P16 | „gezielt aufgebaute KI-Werbung“ | kontrolliertes Endergebnis | korrigierter Rohclip → finaler Werbeclip + End-Hold | NEW_BUILD |

Phase 3 verschiebt Beat-Grenzen an die reale Stimme. Die semantische Reihenfolge bleibt unverändert.
