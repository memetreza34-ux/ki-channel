# Animation Plan — Visual Beats

**Grundsatz:** Inhalt zuerst. Für dieses Reel ist jeder Beat `NEW_BUILD`; keine vorhandene Library-Animation bildet die jeweilige Mechanik exakt genug ab.

| Beat | Sprecherstelle | Gemeinte Aussage | Start → Bewegung → Ende | Umsetzung | Phase-1-Timing |
|---|---|---|---|---|---|
| B1 | „Prompt zu offen“ | Aufgabe ist unbestimmt | eine Promptkarte → öffnet sich → mehrere Ausgänge | NEW_BUILD | S1 früh |
| B2 | „mehrere plausible Bedeutungen“ | mehrere Interpretationen sind gleichzeitig möglich | 1 Route → 4 benannte Äste → alle bleiben plausibel | NEW_BUILD | S1 Mitte |
| B3 | „Ton, Länge, Struktur oder Inhalt“ | konkrete Richtungen unterscheiden sich | vier Karten erscheinen nacheinander → jeweils eigene Form → gleichwertige Auswahl | NEW_BUILD | S1 spät |
| B4 | „welche Richtung sie wählt“ | Nutzer kontrolliert die Auswahl nicht | vier Routen → Fokus wandert → eine Route wird gewählt | NEW_BUILD | S2 früh |
| B5 | „wahrscheinlichste Absicht“ | Modell leitet eine plausible Absicht ab | konkurrierende Pfade → Gewichtung ohne Fake-Zahlen → stärkster Pfad bleibt | NEW_BUILD | S2 Mitte |
| B6 | „an deinem Ziel vorbeigeht“ | plausible Auswahl kann Nutzerziel verfehlen | gewählter Pfad → Zielmarker steht versetzt → sichtbarer Miss | NEW_BUILD | S2 spät |
| B7 | „Ziel, Kontext und Grenzen“ | klare Angaben reduzieren Optionen | drei Chips kommen nacheinander → schließen je einen Ast | NEW_BUILD | S3 früh/mittel |
| B8 | „klarere Richtung“ | ein eindeutiger Pfad bleibt | mehrere Äste → kollabieren → ein sauberer lila Pfad | NEW_BUILD | S3 spät |
| B9 | „kurzen Beispiel“ | Beispiel liefert Referenz | Prompt allein → Beispielkarte dockt an → Referenzrahmen aktiv | NEW_BUILD | S4 früh |
| B10 | „wie das Ergebnis aussehen soll“ | Outputform wird sichtbar vorgegeben | leerer Output → Blöcke ordnen sich → Struktur entspricht Beispiel | NEW_BUILD | S4 spät |
| B11 | „was … erreichen / wissen / Format“ | drei Kernangaben strukturieren Prompting | drei leere Slots → Ziel/Kontext/Format füllen sich → klare Pipeline | NEW_BUILD | S5 Mitte |
| B12 | „Weniger Rätsel, mehr Richtung“ | Abschlussregel | diffuse Wege → verschwinden → ein starker Pfad + Check | NEW_BUILD | S5 Ende |

Phase 3 verschiebt Beat-Grenzen am echten Sprecher. Stimme, Visual Beat, Caption-Fokus und Zustandswechsel müssen denselben Moment treffen.
