# Scene Plan

1. **repo-01 — Ein Ordner mit Gedächtnis:** Ein normaler Projektordner öffnet sich, Dateien werden sichtbar, dahinter entsteht eine Versions-Zeitleiste.
2. **repo-02 — Alles gehört ins Repo:** Code, Bild, Dokumentation und Konfiguration ordnen sich in ein großes Repo; Änderungs-Metadaten erscheinen.
3. **repo-03 — Commits schreiben Geschichte:** Mehrere gespeicherte Zustände bilden eine Timeline; Unterschiede und Rücksprung auf einen früheren Stand werden sichtbar.
4. **repo-04 — Branches schützen den Stand:** Hauptlinie teilt sich in Feature-Branch, Änderung wird separat gebaut, über Pull Request geprüft und wieder zusammengeführt.
5. **repo-05 — Mehr als nur Code:** Dateien, Verlauf und Zusammenarbeit verbinden sich zu einem vollständigen Repository; das Projekt wird als ganze Entwicklung weitergegeben.
