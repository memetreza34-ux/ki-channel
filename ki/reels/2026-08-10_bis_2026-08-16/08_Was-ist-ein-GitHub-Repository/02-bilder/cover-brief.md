# Cover-Brief — Was ist ein GitHub Repository?

## Ziel
Das Cover muss in unter einer Sekunde zeigen: **Ein Repository ist ein Projektordner plus Versionsverlauf und Zusammenarbeit.**

## Verbindliche Bildidee
- vertikal 9:16, eigenständiges Hero-Cover
- links: großer einfacher Projektordner mit wenigen klaren Dateien
- rechts: derselbe Ordner als intelligentes Repository mit sichtbarer Commit-Zeitleiste, einem Branch und zwei kleinen Kollaborations-Avataren
- Mitte: klare Transformation `normaler Ordner → Repository mit Gedächtnis`
- Hauptmotiv nutzt ungefähr 65–75 % der Fläche
- keine winzigen Codefenster
- keine große leere Mitte
- keine generische Roboter-/Gehirn-KI
- kein echtes GitHub-Logo nötig; Inhalt muss auch ohne Markenlogo verständlich sein

## Hook
**`GITHUB-REPO EINFACH ERKLÄRT`**

Alternativ nur bei klar besserer Komposition: **`WAS IST EIN REPOSITORY?`**

Regeln: maximal 4–6 Wörter, oben mittig, sehr groß, höchstens 2 Zeilen, keine Untertitel, keine zweite Erklärung.

## Stil
Hell, clean, hochwertig, technisch und modern. Weiß, `#6E45C9`, `#B98CFF`, `#1A1A2E`; dezentes Grün nur für einen erfolgreichen Merge. Kein Cyberpunk, kein Präsentations-Slide-Look.

## Smartphone-Test
1. Ist `Ordner → Versionsverlauf/Team` sofort erkennbar?
2. Ist das Hauptmotiv ohne Zoomen klar?
3. Ist die Hook sofort lesbar?
4. Keine unnötige leere Fläche?
5. Wirkt es wie ein Social-Media-Cover statt wie eine Folie?

Wenn eine Antwort `nein` ist: neu bauen.
