# Bild-Prompts

## cover-github-repository — `cover.jpg`

**Zweck:** eigenständiges 9:16 Hero-Cover, kein Screenshot des Reels.

**Bild-KI erzeugt:** eine große sofort verständliche Transformation von einem normalen Projektordner zu einem versionierten Repository mit Geschichte und Zusammenarbeit.

**Remotion übernimmt bewusst nicht:** das Cover-Hauptmotiv. Typografie darf nach der Bildgenerierung sauber gesetzt werden, falls die Bild-KI Text nicht zuverlässig erzeugt.

**Prompt:**
`Premium vertical 9:16 social media cover for a German AI and coding education channel. Bright clean white-to-soft-lavender background, sophisticated minimal product-design aesthetic, no cyberpunk, no stock-photo look. Large central before-after transformation occupying 65–75% of the canvas. LEFT: one large simple project folder with four clear file cards representing code, image, documentation and configuration, clean and ordinary. RIGHT: the exact same folder transformed into a modern version-controlled repository: a visible purple commit timeline with several nodes behind it, one clean feature branch splitting and merging back, two subtle collaborator avatar circles, all visually connected to the same project. The transformation must instantly communicate normal folder to project with memory and collaboration. Brand accents #6E45C9 and #B98CFF, dark ink #1A1A2E, subtle success green only at the merge point, smartphone-readable, no real GitHub logo required, no robot brain, no tiny code, no clutter, no huge empty center. Leave a clear top area for one short headline.`

**Hook separat setzen:** `GITHUB-REPO EINFACH ERKLÄRT`

**Crop/Fokus:** Hauptmotiv groß im mittleren 65–75-%-Bereich; Hook oben, maximal 2 Zeilen; keine Untertitel oder Zusatztexte.
