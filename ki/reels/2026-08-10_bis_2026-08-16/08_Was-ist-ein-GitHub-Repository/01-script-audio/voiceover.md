# Voiceover — Was ist ein GitHub Repository?

**137 Wörter · Ziel ungefähr 50–60 s · natürlich sprechen, nicht auf exakt 60,0 s zwingen.**

## Szene 1 — Ein Ordner mit Gedächtnis
Wenn du auf GitHub ein Projekt öffnest, landest du meistens in einem Repository. Ein Repository ist im Grunde der komplette Arbeitsordner eines Projekts – aber mit Gedächtnis.

## Szene 2 — Was darin liegt
Darin liegen Code, Bilder, Dokumentation und Konfigurationsdateien. Git merkt sich zusätzlich, welche Datei wann geändert wurde und wer diese Änderung gespeichert hat.

## Szene 3 — Commits schreiben Geschichte
Jeder gespeicherte Zwischenstand heißt Commit. Viele Commits ergeben eine nachvollziehbare Geschichte: Was wurde geändert, warum und an welchem Punkt funktionierte der Code noch?

## Szene 4 — Branches und Pull Requests
Mit Branches kannst du neue Funktionen getrennt ausprobieren, ohne die stabile Version direkt anzufassen. Ist die Änderung fertig, wird sie über einen Pull Request geprüft und zusammengeführt.

## Szene 5 — Mehr als ein Cloud-Ordner
Darum ist ein Repository mehr als ein Ordner in der Cloud. Es bündelt Dateien, Versionsverlauf und Zusammenarbeit an einem Ort. Wenn jemand dir also ein GitHub-Repo schickt, zeigt er dir nicht nur Code, sondern die komplette Entwicklung des Projekts.
