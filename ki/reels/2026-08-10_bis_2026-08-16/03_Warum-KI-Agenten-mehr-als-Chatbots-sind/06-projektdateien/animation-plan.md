# Animation Plan — Visual Beats

**Grundsatz:** Inhalt zuerst. Jeder Beat ist `NEW_BUILD`; keine bestehende Library-Animation bildet die jeweilige Mechanik exakt genug ab.

| Beat | Sprecherstelle | Gemeinte Aussage | Start → Bewegung → Ende | Umsetzung |
|---|---|---|---|---|
| A1 | „Chatbot wartet“ | klassischer Chat reagiert auf neue Eingabe | Chatkarte → Antwort erscheint → Status wartet | NEW_BUILD |
| A2 | „Agent bekommt ein Ziel“ | Agent startet von einem Ziel | Zielkarte erscheint → Agent wird aktiviert | NEW_BUILD |
| A3 | „mehrere Schritte planen“ | Ziel wird in Teilaufgaben zerlegt | 1 Ziel → 3 verbundene Schritte | NEW_BUILD |
| A4 | „Werkzeuge benutzen“ | Agent hat verfügbare Tools | Agentkern → vier Tool-Karten fahren ein | NEW_BUILD |
| A5 | „suchen / Dateien / Code / Daten“ | verschiedene Werkzeugtypen | Tool-Karten werden nacheinander aktiviert | NEW_BUILD |
| A6 | „nur Text“ vs. Ergebnis | Tools liefern Resultate zurück | Aktivierung → Resultat-Chips fließen zurück | NEW_BUILD |
| A7 | „prüft das Ergebnis“ | Aktion wird nicht nur ausgeführt | Ergebnis → Prüffeld → Status entsteht | NEW_BUILD |
| A8 | „welcher Schritt als Nächstes“ | Entscheidung nach Ergebnis | Prüffeld → nächste Plan-Karte leuchtet | NEW_BUILD |
| A9 | „mächtig“ | Schleife kann selbstständig weiterlaufen | Plan → Tool → Check → Plan als sichtbarer Loop | NEW_BUILD |
| A10 | „Berechtigungen zu weit“ | Handlungsspielraum wächst | enger Kreis → großer Berechtigungsradius | NEW_BUILD |
| A11 | „Fehler mehrere Aktionen“ | ein Fehler kann kaskadieren | erste Fehlaktion → 3 Folgeaktionen kippen rot | NEW_BUILD |
| A12 | „klare Grenzen, erlaubte Tools“ | Guardrails begrenzen System | Tool-Liste → nur freigegebene bleiben aktiv | NEW_BUILD |
| A13 | „Mensch bestätigen“ | kritische Aktion braucht Freigabe | Aktion stoppt am Gate → Mensch-Check erscheint | NEW_BUILD |
| A14 | „Planung, Werkzeuge, Aktionen“ | sichere Agenten verbinden mehrere Ebenen | Sprache + Plan + Tool → kontrollierte Aktion | NEW_BUILD |

Phase 3 verschiebt Beat-Grenzen an die reale Stimme; semantische Reihenfolge bleibt unverändert.
