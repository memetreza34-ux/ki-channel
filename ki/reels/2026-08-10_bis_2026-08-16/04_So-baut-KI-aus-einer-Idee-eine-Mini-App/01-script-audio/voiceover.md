# Voiceover — So baut KI aus einer Idee eine Mini-App

## Szene 1 — Von Idee zu Prototyp
Aus einer einfachen Idee kannst du mit KI heute erstaunlich schnell einen ersten App-Prototyp bauen. Aber „Schreib mir eine App“ ist dafür meistens noch viel zu ungenau.

## Szene 2 — Erst Struktur, dann Code
Zuerst braucht die KI ein klares Ziel, die wichtigsten Funktionen und den gewünschten Ablauf. Daraus entsteht ein Plan für Oberfläche, Eingaben, Logik und Ergebnis.

## Szene 3 — Code wird zusammengesetzt
Danach wird der Code nicht als ein riesiger Block gebaut. Einzelne Bausteine für Oberfläche, Daten und Funktionen entstehen nacheinander und werden zu einem ersten Prototyp verbunden.

## Szene 4 — Der erste Entwurf scheitert
Jetzt kommt der Teil, den viele überspringen: testen. Ein Button kann falsch reagieren, Daten können fehlen oder die Ansicht kann auf dem Handy brechen. Genau hier beginnt die eigentliche Verbesserung.

## Szene 5 — Testen macht ihn brauchbar
Die KI kann Fehler finden und Änderungen vorschlagen, aber du entscheidest, was wirklich richtig ist. Der beste Workflow lautet deshalb: Idee präzisieren, Struktur bauen, Code erzeugen, testen und korrigieren. So wird aus KI-Code Schritt für Schritt ein brauchbarer Prototyp.

**Planungsstand:** 146 Wörter. Die reale Voiceover-Dauer bestimmt in Phase 3 die finale Timeline.
