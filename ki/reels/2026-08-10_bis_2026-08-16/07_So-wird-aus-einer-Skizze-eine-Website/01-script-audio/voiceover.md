# Voiceover — So wird aus einer Skizze mit KI eine echte Website

**147 Wörter · Ziel ungefähr 50–60 s · natürlich sprechen, nicht auf exakt 60,0 s zwingen.**

## Szene 1 — Eine Skizze wird verstanden
Eine grobe Skizze auf Papier kann heute reichen, um mit KI den ersten Entwurf einer echten Website zu bauen. Aber die KI sieht nicht einfach nur Kästen. Sie muss verstehen, was Navigation, Überschrift, Eingabefeld und Button bedeuten.

## Szene 2 — Struktur vor Design
Deshalb beginnt der Prozess mit Struktur: Welche Bereiche gibt es, welche Elemente gehören zusammen und was soll passieren, wenn jemand klickt?

## Szene 3 — Aus Kästen wird Layout
Danach wird aus der Skizze ein sauberes Layout. Abstände, Größen, Farben und Hierarchie werden festgelegt, bevor Code entsteht.

## Szene 4 — Code muss funktionieren
Erst dann baut die KI Komponenten und verbindet die Funktionen. Ein Button muss nicht nur aussehen wie ein Button, sondern tatsächlich etwas auslösen.

## Szene 5 — Testen, korrigieren, verbessern
Jetzt folgt der wichtigste Schritt: testen. Stimmen Mobilansicht, Eingaben, Zustände und Fehlermeldungen? Wenn etwas nicht passt, wird nicht alles neu gebaut. Die KI korrigiert gezielt die betroffene Stelle. So wird aus einer schnellen Zeichnung kein perfektes Produkt auf Knopfdruck, aber ein funktionierender Prototyp, den du weiter verbessern kannst.
