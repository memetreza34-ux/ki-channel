# Scene Plan

| Szene | Sprecherfunktion | Headline | Sichtbare Hauptmechanik |
|---|---|---|---|
| 1 | Hook + KI muss Skizze semantisch verstehen | KI liest mehr als Kästen | Papier-Wireframe → Rollen Navigation/Headline/Input/Button |
| 2 | Struktur und Interaktion definieren | Struktur vor Design | Seitenzonen + Element-Gruppen + Klickpfad |
| 3 | Wireframe visuell präzisieren | Aus Wireframe wird Layout | Grid, Spacing, Größen, Farben, Hierarchie |
| 4 | aus Design echte Funktion machen | Design wird Funktion | Komponenten + Event-Pfad + sichtbarer State-Wechsel |
| 5 | responsive testen, minimal korrigieren, verifizieren | Testen macht es echt | Desktop/Mobile-Test → gezielter Patch → fertiger Prototyp |
