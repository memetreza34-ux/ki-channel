# Cover-Brief — Skizze → Website

## Ziel
Das Cover muss in unter einer Sekunde zeigen: **einfache Handskizze → hochwertige funktionierende Website**.

## Verbindliche Bildidee
- vertikal 9:16, eigenständiges Hero-Cover
- links: großes weißes Papier mit klarer handgezeichneter Website-Skizze, schwarzer Stift, wenige große UI-Kästen
- rechts: exakt dieselbe Struktur als hochwertige moderne Website auf einem großen Browser-/Laptop-Screen
- Mitte: kontrollierter violetter Transformationspfad von gezeichneten Linien zu sauberem Interface
- Hauptmotiv nutzt ungefähr 65–75 % der Fläche
- keine kleinen Dashboard-Karten als Hauptmotiv
- keine generische Roboter-/Gehirn-KI
- keine realen Logos
- keine große leere Mitte

## Hook
**`SKIZZE → WEBSITE`**

Alternativ nur wenn die Komposition deutlich besser ist: **`VON PAPIER ZU CODE`**

Regeln: maximal 4–6 Wörter, oben mittig, sehr groß, höchstens 2 Zeilen, keine Untertitel, keine zweite Erklärung.

## Stil
Hell, clean, hochwertig, modern, natürlich-tech. Weiß, `#6E45C9`, `#B98CFF`, `#1A1A2E`; keine Neon-Cyberpunk-Optik, kein Präsentations-Slide-Look.

## Smartphone-Test
1. Ist Skizze → Website sofort erkennbar?
2. Sind beide Zustände ohne Zoomen verständlich?
3. Ist die Hook sofort lesbar?
4. Keine unnötige leere Fläche?
5. Wirkt es wie ein starkes Social-Media-Cover?

Wenn eine Antwort `nein` ist: neu bauen.
