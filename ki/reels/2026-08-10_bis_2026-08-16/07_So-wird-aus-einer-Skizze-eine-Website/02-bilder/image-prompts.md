# Bild-Prompts

## cover-sketch-website — `cover.jpg`

**Zweck:** eigenständiges 9:16 Hero-Cover, kein Screenshot des Reels.

**Bild-KI erzeugt:** klare Vorher/Nachher-Transformation derselben Website-Idee: links handgezeichnete Skizze auf Papier, rechts professionell umgesetzte Website.

**Remotion übernimmt bewusst nicht:** das Cover-Hauptmotiv. Hook bei Bedarf anschließend sauber setzen.

**Prompt:**
`Premium vertical 9:16 social media cover for a German AI creation and coding channel. Bright clean white-to-soft-lavender background, polished modern creative-tech aesthetic, natural and premium, no cyberpunk. Large split hero composition occupying 65–75% of the canvas. LEFT: a real sheet of white paper viewed slightly from above, one bold hand-drawn website wireframe in dark ink with a header, hero area, input field and button, simple and immediately readable, a black pen nearby. RIGHT: the exact same structure transformed into a sophisticated finished responsive website on a large clean browser or laptop screen, premium spacing, clear typography blocks, elegant purple accents #6E45C9 and #B98CFF, dark ink #1A1A2E. BETWEEN: one controlled purple transformation line where rough sketch strokes become precise interface geometry, strong directional before-to-after story, no generic AI brain, no robot, no tiny code windows, no real logos, no clutter, no huge empty center. Leave a clear top area for one short German headline.`

**Hook separat setzen:** `SKIZZE → WEBSITE`

**Crop/Fokus:** Transformation groß in der Mitte; Hook oben, maximal 2 Zeilen; keine Untertitel oder Zusatztexte.
