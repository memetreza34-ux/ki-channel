# Cover-Brief — So findet KI den Bug im Code

## Ziel
Das Cover muss in unter einer Sekunde zeigen: **kaputte App → KI-Debugging → überprüfter Fix**.

## Verbindliche Bildidee
- vertikal 9:16, eigenständiges Hero-Cover
- links: große kaputte App-Oberfläche direkt nach einem Button-Klick
- rechts: exakt dieselbe App im funktionierenden Zustand
- Mitte: klarer Debugging-Trace als kontrollierte Verbindung vom Fehler zum Fix
- Hauptmotiv nutzt ungefähr 65–75 % der Fläche
- keine kleinen Codefenster als Hauptmotiv
- keine große leere Mitte
- keine generische Roboter-/Gehirn-KI
- keine realen Logos

## Hook
**`CODE KAPUTT → KI-FIX?`**

Alternativ nur bei klar besserer Komposition: **`KI FINDET DEN BUG?`**

Regeln: maximal 4–6 Wörter, oben mittig, sehr groß, höchstens 2 Zeilen, keine Untertitel, keine zweite Erklärung.

## Stil
Hell, clean, hochwertig, technisch, aber nicht Cyberpunk. Weiß, `#6E45C9`, `#B98CFF`, `#1A1A2E`; semantisches Rot nur für den Fehler und zurückhaltendes Grün nur für den erfolgreichen Fix.

## Smartphone-Test
1. Ist `kaputt → fix` sofort erkennbar?
2. Sind App und Fehler ohne Zoomen lesbar?
3. Ist die Hook sofort lesbar?
4. Kein Präsentations-Slide-Look?
5. Keine unnötige leere Fläche?

Wenn eine Antwort `nein` ist: neu bauen.
