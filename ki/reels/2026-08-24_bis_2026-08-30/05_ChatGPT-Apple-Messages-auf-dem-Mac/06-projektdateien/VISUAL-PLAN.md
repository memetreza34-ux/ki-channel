# Step 3 — Visual Plan: ChatGPT + Apple Messages

## Ziel

Das Reel soll lebendiger wirken, ohne die klare Produkt-UI zu verlieren. Deshalb: kontrollierte Kamera statt hektischer Effekte.

## Szene 1 — Verbindung

- leichter Push-In auf Messages ↔ ChatGPT
- minimale Parallax-Bewegung beider Karten
- Fokus-Halo auf `VERBUNDEN`
- keine externe Bilddatei: native UI erklärt den Mechanismus präziser

## Szene 2 — Suche

- Kamera fokussiert zuerst das Suchfeld
- Scan-Sweep durch die Suche
- danach Fokus auf die Ergebnisgruppe iMessage / SMS / RCS
- zwei klar getrennte visuelle Beats statt einer statischen Karte

## Szene 3 — Entwurf / Senden

- erster Fokus auf den Antwortentwurf
- zweiter Fokus auf den Send-Button
- Push-In verschiebt die Aufmerksamkeit Richtung Aktion

## Szene 4 — Freigabe

- Kamera zieht in den Freigabedialog
- Fokus zuerst auf Nachricht + Empfänger
- danach Fokus auf `SENDEN FREIGEGEBEN`
- Sicherheitsmechanik bleibt lesbar, kein überladener Effekt

## Szene 5 — Verfügbarkeit / Quelle

- subtile Parallax auf macOS / Alle-Tarife-Karten
- leichter finaler Push-In
- sichtbare native Source-Proof-Karte: `OpenAI Release Notes • 20. Aug. 2026`
- keine komplette Webseitenkopie; Quelle dient als Beleg und visueller Wechsel

## Qualitätsregeln

- Zoom pro Fokusbeat klein halten: grob 1.03–1.055
- kein permanentes Rein-/Rauszoomen
- kritischer Text bleibt vollständig im Safe-Bereich
- Caption-Layer bleibt über allen Visuals
- SFX bleiben an den bestehenden visuellen Event-Frames
- finale Beurteilung ausschließlich am neuen 1x-MP4
