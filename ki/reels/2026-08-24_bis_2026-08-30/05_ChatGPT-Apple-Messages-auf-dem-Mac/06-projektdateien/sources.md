# Quellen / Faktenlock

## Offizieller OpenAI-Faktenstand

OpenAI Release Notes, 20. August 2026:

- Apple Messages Plug-in für ChatGPT Desktop auf macOS
- kann Messages-Chats auf dem Mac lesen und durchsuchen
- kann Nachrichten vorbereiten oder senden
- laut Release Notes auf allen Tarifen verfügbar
- standardmäßig wird erst nach Freigabe von Nachricht und Empfänger gesendet

OpenAI Help Center ergänzt für Apple-silicon Macs: iMessage-, SMS- und RCS-Unterhaltungen können gelesen und durchsucht werden.

## Quellen

- https://openai.com/products/release-notes/
- https://help.openai.com/en/articles/6825453-chatgpt-release-notes

## Nicht behaupten

- keine Aussage, dass ChatGPT ohne Verbindung/Berechtigung private Nachrichten sehen kann
- keine Aussage, dass jede macOS-/Hardware-Konfiguration unterstützt wird
- keine Aussage, dass Nachrichten ohne Freigabe standardmäßig automatisch versendet werden
