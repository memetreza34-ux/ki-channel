# Reel Visual QA

Review only current artifacts from the current commit: every checkpoint, contact sheet, full MP4 at normal speed, phone-size playback and active-word tracking with audio.

Score immediate clarity, semantic match, synchronization, motion quality, contrast, phone readability and result hold. Any score below 8/10 blocks release.

Block repetitive card sliding, weak contrast, empty visual areas, tiny labels, wrong active word, wrong sentence count, progress lines, mistimed action and stale renders.
