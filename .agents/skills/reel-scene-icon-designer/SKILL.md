# Reel Scene Icon Designer

Use for every scene before coding the final heading.

Each heading icon must:

- communicate the scene idea without text
- use simple SVG geometry
- match the brand palette
- remain readable around 90 × 90 px on a phone
- animate only one meaningful property
- react to a relevant transcript trigger
- avoid generic sparkles, random robot heads and decorative loops
- differ semantically from the other scene icons

Document per scene:

```text
heading → icon metaphor → transcript trigger → micro-motion → final state
```

The icon supports the heading; it must never replace the main explanatory animation.
