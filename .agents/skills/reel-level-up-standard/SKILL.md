# Reel Level-Up Standard

Use this skill for every new 60–75 s KI reel after the base storytelling contract is satisfied. It exists to prevent a technically good reel from still feeling like a polished slide deck.

## 1. Brand fidelity is mandatory when a brand/product is central

If the spoken story repeatedly names a company, product or tool, make an explicit brand-identity decision before implementation.

Preferred order:

1. local, provenance-backed official logo/wordmark when permitted for factual/editorial reference;
2. local screenshot/crop of the real product or official source page when it proves the claim better;
3. plain typographic brand name if a real asset cannot be safely used.

Never substitute an unrelated generic icon and present it as if it were the brand logo. Lucide/iconography may describe a function (API key, code, safety, network, owner) but must not impersonate OpenAI, Cursor, SpaceX or another named brand.

If a brand asset is unavailable or usage is uncertain, show the brand name as text and keep the functional icon visually separate.

## 2. At least one real proof moment for branded/current-news stories

For stories about a real company/product/update, target at least one strong real proof moment when a suitable official source exists:

- official announcement page crop;
- official help-center/product UI crop;
- real app/tool UI;
- official document/diagram.

Use Chrome DevTools / Browser Agent to inspect the official source when useful. Selected visual media must still be local before render and keep source/provenance. Use Sharp prep only after the asset is local and rights/provenance are documented.

A stylized `SourceProofCard` is useful metadata, but it does not always replace a real screenshot when visual proof materially improves trust.

## 3. Word-locked semantic timing after user audio

Sentence-progress timing is a fallback. After forced alignment, major visual and SFX payoffs should anchor to the exact word/phrase whenever practical.

Examples:

- say "SpaceX" → ownership card/logo lands on that phrase;
- say "12. November" → date impact lands on that phrase;
- say "Astra" → Astra object enters on that phrase;
- say "API-Key" → API-key route appears on that phrase.

The viewer may receive a tiny anticipatory motion cue, but the information reveal itself must not substantially precede the spoken phrase.

Future beat contracts should prefer `anchorPhrase` / `anchorWord` plus fallback `sentenceId + progress` rather than static scene percentages alone.

## 4. Motion grammar diversity, not merely more beats

A 60–75 s reel should use multiple motion families. Target at least five where relevant:

- spatial path/connector motion;
- object transform/collision/physical reaction;
- kinetic number/date/text impact;
- camera push/reframe/depth;
- timeline/progress/playhead;
- routing/branching/gate state;
- real-source crop/highlight motion;
- 3D/Skia/Lottie/Rive hero moment;
- selective transition/cut flash;
- full-frame environmental/diagram scene.

Do not allow more than two consecutive important beats to use the same `card slides in + spring` grammar.

At least one major scene should be primarily spatial/full-frame rather than a collection of white cards whenever the topic allows it.

## 5. Use the full vertical stage

Treat 1080×1920 as one continuous stage from the chapter/headline down to the raised caption-safe zone.

- avoid large unexplained empty middle zones;
- allow major objects to grow much larger than card components;
- use foreground/background/depth layers;
- let timelines, routes and physical metaphors travel through the frame;
- do not cluster every information object around the same y-range.

Negative space is deliberate only when it increases focus or tension.

## 6. Microdetails must remain phone-readable

Dates, status labels, route counters and source metadata are good, but tiny decorative text is not.

- prefer fewer useful microdetails over many unreadable ones;
- target roughly 22–26 px minimum for important microdetails in 1080×1920;
- state tags such as `PROPOSED`, `FINAL`, `PENDING`, `1/3`, exact dates and source names should be readable on a phone;
- reveal secondary details progressively instead of showing all fine print at once.

## 7. SFX follow semantic action

Increase SFX density only when the visual event density increased.

Useful triggers include:

- connector completes;
- ownership/object lands;
- cable breaks;
- date locks;
- gate rejects;
- route activates;
- real source proof snaps into focus;
- final payoff resolves.

Do not sound every text entrance. Voice remains dominant.

## 8. Real-render level-up review

On the exact mastered MP4, explicitly review:

- `BRAND_FIDELITY`
- `REAL_PROOF_MOMENT`
- `NO_FAKE_BRAND_ICON`
- `WORD_LOCKED_MAJOR_REVEALS`
- `MOTION_GRAMMAR_DIVERSITY`
- `NO_CARD_DECK_FEEL`
- `FULL_VERTICAL_STAGE_USE`
- `MICRODETAILS_PHONE_READABLE`
- `SFX_SEMANTIC_DENSITY`
- `VOICE_PRIORITY_OVER_SFX`

Do not infer these from source code. A future reel is levelled up only after the real render proves them.
