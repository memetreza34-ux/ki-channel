# Denkwürfel

Erklärkanal für Allgemeinwissen in Zahlen – Biologie, Geschichte, Politik, Geographie und mehr – als 9:16-Shorts, gebaut mit Remotion.

- Alles Wichtige steht in `studio/CLAUDE.md`.
- Baukasten und Beispiele: `studio/projekte/wissen/`.
- Produktion: Skill `wissens-short` (in `.claude/skills/`), Prüfung: Agent `video-kritiker`.
- Kanal-Ordner für Skripte, Aufnahmen und Exporte: `kanal/`.

Start: `npm run studio` · Prüfbilder: `npm run look -- <ID>` · MP4: `npm run render -- <ID>`
