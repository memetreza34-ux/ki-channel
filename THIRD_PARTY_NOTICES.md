This repository contains project-specific code and documentation that adapts motion-design architecture and production ideas from the following MIT-licensed open-source projects.

## remotion-motion-graphics-skill

Source: https://github.com/jturntdev/remotion-motion-graphics-skill

Copyright (c) 2026 Promptible

Licensed under the MIT License. The project is used as a reference for motion-direction principles such as continuous-world choreography, hold → move → hold camera grammar, one primary action per beat, micro-motion during holds, and reference-driven review.

## remotion-cinematic

Source: https://github.com/codeverbojan/remotion-cinematic

Copyright (c) 2026 remotion-cinematic contributors

Licensed under the MIT License. The project is used as an architectural reference for scene-relative/keyframed camera timelines and continuous world-coordinate motion.

## remotion-bits

Source: https://github.com/av/remotion-bits

Licensed under the MIT License. The project is used as an architectural reference for staggered multi-state motion, 3D layout transformation, reassembly and mosaic-style state changes.
