# KI-Channel

Lies zuerst:

1. `alles/AGENTS.md`
2. `alles/ki/reel-brain/PRODUCTION-BRAIN.md`
3. für jedes neue Reel `alles/ki/reel-brain/FUTURE-REEL-STANDARD.md`
4. `alles/ki/reel-brain/brain.json`
5. `alles/ki/reel-brain/VALIDATION.md`

Neue Reels verwenden standardmäßig:

- 60 bis 70 Sekunden
- 125 bis 145 Wörter
- 8 bis 9 Szenen
- 100 Prozent Remotion-Animation
- keine generierten Szenenbilder
- ein separates statisches Cover mit einem Satz
- Voiceover bei 1,00x
- maximal zwei starke Bewegungen gleichzeitig
- normale Satzuntertitel

Benutzerprojekte liegen in `reels/` und `youtube/`. Der technische Code liegt vollständig in `alles/`.

FinanzNeo ist ein eigenständiges Repository und darf hier nicht erneut angelegt oder eingebunden werden. Historische Hybrid-Reels dürfen bestehen bleiben, sind aber keine Vorlage für neue Reels.
