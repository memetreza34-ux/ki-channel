# Animation plan

Codex must implement this plan rather than inventing a new visual concept.

## Global choreography

- 1080 × 1920, 30 FPS
- one dominant explanatory motion per scene
- maximum three strong motions at once
- every scene: hold → cause → movement → effect → result hold
- subtitles reveal only already-spoken words
- compact subtitle window, normally 7–10 words
- important words receive semantic animation
- hard cuts by default
- no fade to black
- no flat image with generic zoom only
- voiceover-only by default
