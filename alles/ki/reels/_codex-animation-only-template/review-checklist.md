# Review-Checkliste

## Script

- [ ] direkter Hook
- [ ] 125 bis 145 Wörter
- [ ] 60 bis 70 Sekunden echte Dauer
- [ ] keine künstlichen Füllsätze
- [ ] ein Hauptgedanke pro Szene

## Animation

- [ ] Reel vollständig in Remotion animiert
- [ ] keine generierten Szenenbilder
- [ ] jede wichtige Bedeutung besitzt eine passende Reaktion
- [ ] maximal zwei starke Bewegungen gleichzeitig
- [ ] höchstens vier Bedeutungsbeats pro Szene
- [ ] mindestens eine Sekunde Ergebnis-Hold pro Szene
- [ ] keine schnellen Effektketten
- [ ] keine wiederholte Vollchoreografie

## Untertitel

- [ ] echte Transcript-Zeitpunkte
- [ ] normale Satzuntertitel
- [ ] maximal zwei Zeilen
- [ ] mindestens 40 px
- [ ] nur bereits gesprochene Wörter
- [ ] kein Bounce des gesamten Satzes

## Cover

- [ ] genau eine statische Bilddatei
- [ ] genau ein Hauptmotiv
- [ ] genau ein deutscher Satz
- [ ] keine weiteren Labels oder Botschaften
- [ ] Smartphone-Lesbarkeit geprüft

## Technik und Freigabe

- [ ] TypeScript bestanden
- [ ] fokussierte Tests bestanden
- [ ] aktuelle Checkpoint-Frames gerendert
- [ ] Kontaktbogen geprüft
- [ ] aktuelles MP4 vollständig angesehen
- [ ] normale Geschwindigkeit geprüft
- [ ] Smartphone-Größe geprüft
- [ ] technische Artefaktprüfung bestanden
- [ ] Nutzerfreigabe vorhanden
