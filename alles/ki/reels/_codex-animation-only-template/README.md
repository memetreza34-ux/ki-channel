# Animation-only Reel Template v3

Jedes neue Reel verwendet:

- 125 bis 145 Wörter
- 8 bis 9 Szenen
- genau zwei kurze Sätze pro Szene
- beide Sätze vollständig sichtbar
- aktives gesprochenes Wort violett
- keine Fortschrittslinie
- ein großes Hauptobjekt und eine dominante Bewegung pro Szene
- finale Wort- und Beat-Zeiten ausschließlich aus `timeline/final-sync.json`

Vor Freigabe sind Animation Director, Sync Auditor und Visual QA Agent Pflicht.
