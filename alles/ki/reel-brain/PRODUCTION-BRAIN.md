# KI-Reel-Produktionsgehirn

Aktiver Standard: `ki-animation-only-reel-v4`.

```text
Thema und Script
→ pro Szene zwei kurze Voiceover-Sätze planen
→ Animation Director entwirft Hauptobjekt, Ursache-Wirkung-Bewegung und Ergebnis
→ Icon Designer entwirft passendes Überschriften-Icon
→ Remotion-Vorbau
→ finales Voiceover bei 1,00x
→ echtes Wort-Transcript
→ final-sync.json
→ Einzel-Satz-Untertitel mit violettem Wort-Tracking
→ v4-Validator
→ TypeScript und Tests
→ Smoke-Frames
→ Checkpoints, Kontaktbogen, Cover und MP4
→ normale und Smartphone-Sichtprüfung
→ Nutzerfreigabe
```

Der aktuelle Satz steht vollständig und alleine. Das aktive Wort wird violett; es gibt keine Fortschrittslinie oder große Untertitelbox. Jede Überschrift besitzt ein semantisches Vektor-Icon. Jede Szene erklärt ihre Aussage mit einem großen Objekt und einer klaren Zustandsänderung statt mit wiederholten kleinen Karten oder Rahmen.

Historische v1-, v2- und v3-Reels bleiben reproduzierbar, sind aber keine Vorlage für neue Produktionen.
