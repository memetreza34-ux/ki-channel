# KI-Reel-Gehirn

Dieses Verzeichnis ist die dauerhafte Produktionslogik für alle KI-Reels.

Codex muss vor jeder Reel-Arbeit lesen:

1. `alles/AGENTS.md`
2. `alles/ki/reel-brain/PRODUCTION-BRAIN.md`
3. den konkreten Reel-Ordner

`brain.json` enthält dieselben Kernregeln maschinenlesbar. Die Planung eines einzelnen Reels darf die globalen Qualitätsregeln verschärfen, aber nicht heimlich abschwächen.
