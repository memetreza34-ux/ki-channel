# Kanal

```text
shorts/<Montag>_bis_<Sonntag>/<thema>/
  audio/    script.txt zum 1:1-Vorlesen · Aufnahme hier rein
  export/   video.mp4 · caption.txt (Titel, Beschreibung, Quellen, Hashtags)
```

Phase 1: Claude legt den Ordner an und schreibt `audio/script.txt`.
Phase 2: Arman legt die Aufnahme in `audio/`.
Phase 3: Claude baut das Video im Studio (`studio/projekte/wissen/` bzw. eigenes Projekt) und füllt `export/`.

`youtube/` ist das Archiv der bisherigen langen KI-Videos.
