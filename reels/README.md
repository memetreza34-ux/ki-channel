# Reels

Ordnerfolge: `Woche / Wochentag / Reel-Thema`.

Neue Reels verwenden `ki-animation-only-reel-v3`:

- 125 bis 145 Wörter
- 8 bis 9 Szenen
- genau zwei kurze Sätze pro Szene
- beide Sätze vollständig sichtbar
- aktives Wort violett
- keine Fortschrittslinie
- Untertitel standardmäßig 260 px über dem unteren Rand
- ein großes Hauptobjekt und eine dominante Bewegung pro Szene
- echtes Voiceover als einzige finale Zeitquelle

Aus `alles/` anlegen und danach mit `validate-reel-v3.mjs` prüfen.
