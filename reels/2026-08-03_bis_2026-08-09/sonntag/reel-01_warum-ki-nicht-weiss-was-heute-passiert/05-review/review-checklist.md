# Review-Checkliste

## Untertitel

- [ ] immer nur ein Satz sichtbar
- [ ] vollständiger Satz erscheint sofort
- [ ] aktives Wort folgt dem echten Voiceover exakt
- [ ] in Pausen ist kein Wort violett
- [ ] Unterkante liegt bei 320 px
- [ ] keine Fortschrittslinie oder große Hintergrundbox

## Animation

- [x] acht unterschiedliche Hauptmechaniken geplant
- [x] acht unterschiedliche semantische Icons angelegt
- [x] keine wiederholte weiße Rahmenbühne
- [x] keine Mini-Dashboards als Hauptvisual
- [ ] jeder Schlüsseltrigger liegt höchstens fünf Frames von der Stimme entfernt
- [ ] jeder Endzustand bleibt mindestens eine Sekunde lesbar
- [ ] alle Hauptobjekte sind auf Smartphone-Größe sofort verständlich

## Technik und Freigabe

- [ ] genau eine finale Audiodatei vorhanden
- [ ] echtes Wort-Transcript vorhanden
- [ ] `final-sync.json` aus dem echten Audio erzeugt
- [ ] v4-Validator bestanden
- [ ] Anti-Wiederholungs-Validator bestanden
- [ ] TypeScript bestanden
- [ ] fokussierte Tests bestanden
- [ ] aktuelle Smoke-Frames geprüft
- [ ] Kontaktbogen geprüft
- [ ] aktuelles MP4 normal und in Smartphone-Größe angesehen
- [ ] Nutzerfreigabe
