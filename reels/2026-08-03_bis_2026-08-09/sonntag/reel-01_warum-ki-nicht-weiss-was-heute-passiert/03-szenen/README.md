# Szenenstrategie

Jede Szene verwendet eine andere visuelle Mechanik:

1. unterbrochene Live-Verbindung
2. einfrierender Trainingsdaten-Kristall
3. Zeitlinie hinter einer Wissensgrenze
4. falsches Muster füllt eine Wissenslücke
5. Web-Suchstrahl holt Quellen
6. Frische-Scanner sortiert Quellen
7. Zusammenfassung entfaltet sich zur Originalquelle
8. zwei Quellen laufen durch ein Prüfprisma

Keine Szene basiert als Hauptidee auf kleinen Karten, Standardbalken oder einem wiederholten Dashboard.
