# Video-Untertitel

- normale Satzuntertitel
- keine hektischen Zwei- bis Vier-Wort-Blöcke
- maximal zwei Zeilen
- ungefähr 50 px, mindestens 40 px
- weiß mit dunkler Kontur oder starkem Schatten
- kein großer Untertitelkasten
- nur bereits gesprochene Wörter anzeigen
- aktuelles wichtiges Wort dezent violett hervorheben
- kein Bounce des gesamten Satzes
- finale Zeitpunkte aus dem echten Wort-Transcript

Die im Code eingebauten Cues sind nur ein planbarer Fallback. Vor der finalen Freigabe muss Codex sie durch reale Wortzeiten aus dem gelieferten Voiceover ersetzen.
