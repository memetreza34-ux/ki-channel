# Szenen

Alle neun Szenen sind vollständig in Remotion programmiert. Es werden keine generierten Szenenbilder benötigt.

## Choreografie-Grundregel

```text
klarer Startzustand
→ gesprochenes Schlüsselwort
→ passende Hauptbewegung
→ sichtbare Erklärung
→ mindestens eine Sekunde ruhiger Ergebnis-Hold
```

- maximal zwei starke Bewegungen gleichzeitig
- maximal vier Bedeutungsbeats pro Szene
- keine schnellen Effektketten
- keine zufälligen Partikel oder Dauerpulse
- Hard Cuts als Standard
- jede Szene besitzt eine andere Layout- und Bewegungssignatur
