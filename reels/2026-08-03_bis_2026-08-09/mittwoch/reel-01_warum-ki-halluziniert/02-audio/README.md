# Audio hier einfügen

Lege genau **eine** Audio- oder Mediendatei direkt in diesen Ordner.

Unterstützt:

```text
.wav .mp3 .m4a .aac .ogg .mp4 .mov .webm
```

Der Dateiname ist egal. Auch eine MP4-Datei wird akzeptiert, wenn sie eine Audiospur besitzt.

Die Quelldatei wird bei 1,00x erzeugt und für das Reel pitch-erhaltend auf 1,10x verarbeitet. Keine Musik oder Soundeffekte einbauen.
