# Voice-Script

- `script-fliesstext.txt` ist der Text zum direkten Kopieren in das Voice-Tool.
- `script.md` zeigt die Zuordnung zu allen acht Szenen.
- `voiceover-anweisung.txt` enthält die Aufnahme- und Geschwindigkeitsregeln.

Der Text wird bei 1,00× erzeugt. Remotion verarbeitet ihn später auf 1,10×.
