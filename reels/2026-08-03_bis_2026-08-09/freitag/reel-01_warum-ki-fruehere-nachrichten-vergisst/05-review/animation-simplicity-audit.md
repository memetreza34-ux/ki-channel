# Animations-Einfachheitsprüfung

| Szene | Hauptobjekt | dominante Bewegung | Sinnbeats | Ergebnis |
|---|---|---|---:|---|
| 1 | Chat-Spur im Fenster | alte Karte verlässt Rahmen | 2 | nur Fensterinhalt aktiv |
| 2 | lange Chat-Spur | Spur entfaltet sich | 2 | begrenzter Ausschnitt |
| 3 | Chat-Spur plus Fenster | Fenster wandert rechts | 2 | aktueller Kontext verschoben |
| 4 | linke Fenstergrenze | alte Karte überschreitet Grenze | 3 | Information nicht verfügbar |
| 5 | Kapazitätsfenster | große Blöcke füllen Platz | 3 | Kontext voll |
| 6 | Suchstrahl | Suche stoppt an Grenze | 3 | Details fehlen |
| 7 | Chat-Spur | alte Inhalte verdichten sich | 3 | wichtiger Kontext passt |
| 8 | sauberes Fenster | drei Module rasten ein | 3 | sichtbarer Kontext zählt |

## Globale Prüfung

- [x] maximal ein Hauptobjekt pro Szene
- [x] maximal eine dominante Bewegung pro Szene
- [x] maximal drei Sinnbeats
- [x] keine Mini-Dashboards
- [x] keine permanenten Szenennummern
- [x] keine permanenten Kicker
- [x] keine Emojis als Hauptvisual
- [x] keine Szenenbilder
- [ ] nach Render visuell bestätigt
