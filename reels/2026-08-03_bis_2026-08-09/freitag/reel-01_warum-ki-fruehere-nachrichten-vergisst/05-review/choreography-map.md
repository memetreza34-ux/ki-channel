# Choreografie-Karte

Das Reel folgt einem einzigen verständlichen Objektfluss:

```text
Chat-Spur sichtbar
→ Kontextfenster begrenzt den Ausschnitt
→ neue Nachricht verschiebt das Fenster
→ alte Nachricht verlässt den Ausschnitt
→ große Inhalte füllen die Kapazität
→ frühere Details fehlen
→ Inhalte werden verdichtet und neu eingebracht
→ relevanter Kontext sitzt wieder im Fenster
```

Die Szenen verwenden unterschiedliche räumliche Blickpunkte, behalten aber dieselbe visuelle Logik. Dadurch entsteht Abwechslung ohne einen Stilbruch.
