# Cover

## Text

```text
WARUM VERGISST DEINE KI FRÜHERE NACHRICHTEN?
```

## Motiv

Eine lange Chat-Spur läuft durch ein begrenztes transparentes Kontextfenster. Neue Nachrichten bleiben violett und klar; ältere Karten verlassen links den Rahmen und verblassen.

Der vollständige Bildprompt steht in `cover.txt`.

Die Composition `Cover-WhyAIForgetsEarlierMessages` kann das Cover ohne externes Bild als saubere Vektorgrafik rendern. Das Cover enthält keine Unterzeile und keine zweite Botschaft.
