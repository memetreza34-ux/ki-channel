# Untertitel

- kompletter aktueller Satz oder Sinnabschnitt erscheint sofort
- Text bleibt während der gesamten Cue-Dauer stabil
- nur eine violette Linie läuft synchron zur Stimme
- keine Wort-für-Wort-Enthüllung
- keine einzelne Wortmarkierung
- maximal zwei Zeilen
- 50 px Standard, niemals unter 42 px
- Unterkante: 220 px
- kein großer Hintergrundkasten
- finale Zeitpunkte ausschließlich aus `timeline/final-sync.json`

Vor dem finalen Audio dürfen keine geschätzten Cues als synchron bezeichnet werden.
