# Szenen und Choreografie

Alle acht Szenen sind vollständig in Remotion gebaut. Es werden keine Szenenbilder benötigt.

Das wiederkehrende Hauptobjekt ist eine lange Chat-Spur, die durch ein begrenztes transparentes Kontextfenster läuft. Dadurch bleibt die Erklärung über das gesamte Reel zusammenhängend.

## Grundrhythmus

```text
vollständiges Hauptobjekt sofort erkennbar
→ gesprochener Sinnabschnitt löst eine Bewegung aus
→ eine Hauptbewegung erklärt den Inhalt
→ Ergebnis bleibt mindestens eine Sekunde ruhig sichtbar
```

## Grenzen

- ein Hauptobjekt pro Szene
- eine dominante Bewegung pro Szene
- maximal zwei kleine unterstützende Elemente
- maximal drei Sinnbeats
- keine Mini-Dashboards
- keine Wort-für-Wort-Animationen
- keine zufälligen Partikel
- keine dauerhaften Szenennummern oder Kicker
- Untertitel stehen separat bei 220 px und zeigen sofort den kompletten Satz
